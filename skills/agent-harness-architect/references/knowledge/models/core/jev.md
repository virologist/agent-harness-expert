## 一句话定位

TypeSafe 推出的首个公开 System One 模型（决策型，2026-09-15 发布）：给定状态与封闭候选集，直接输出类型化决策（选择/评分/是否概率），承接 agent 循环中高频、窄幅的快速决策。

## 接口形态

- 托管 API：`POST /v1/decisions`（api.typesafe.ai），模型名 `jev-latest`，需 API key（early access waitlist）。
- 三原语：Choice（单选，≤255 个选项）/ Score（2–10 级评分）/ Noul（是/否概率）。仅文本输入。
- 对应四分类中的「决策型模型（System One）」档位；与 CLM-8B 同一 wire schema（TypeSafe 兼容），互为同档替代。
- 来源：TypeSafe 官方文档 + 官方博客（2026-09-28 核实）。

## 延迟 / 成本量级

- 官方自报延迟 70–500ms（2026-09-28 核实）。
- 官方自报价格约 $0.042/M 输入 token、输出免费（2026-09-28 核实）。
- 以上均为量级基线：early access 阶段价格与配额可能变动，落地以用户实测与厂商当期价目为准。

## 已验证适用域

- 封闭候选集的类型化窄决策：分类/路由/门控（Choice）、程度评分（Score）、是否判断（Noul）——来源：官方文档三原语定义。
- 高频重复决策的成本敏感场景（低单价 + 毫秒级延迟量级）——来源：官方定位博客。

## 已验证不适用域

- 官方暂未自报负结果（early access 阶段）。
- **unverified 待核线索**（不得作为高可信建议依据）：难度路由（以其输出作任务难度路由器）≈ 无信号、轨迹归因 ≈ 随机；唯一来源为个人博客基准，待官方或可追溯来源复核。按「已验证不适用域」来源分级通则，第三方/个人来源负结果一律记 unverified。
- 官方约束（边界而非负结果）：仅文本输入；单次 Choice 上限 255 选项，超出需分块锦标赛。

## 降级策略

- 限流/故障：同窄决策降级到快速低价 LLM 档位（验证采样率相应上调），或候选集有确定性特征时降级为确定性规则。
- 涨价/不可用：同档同 schema 替换——自托管 CLM-8B（TypeSafe 兼容 API，客户端改动最小，见 clm-8b 条目）。
- 降档方向：决策型 → 确定性规则；若发现窄决策实际需要开放推理，属路由错误，应回归强力 LLM 档位而非换同档模型。

## 设计启发

- 四分类中「决策型模型（System One）」档位的对照物：设计任务-模型分派表时，用它回答"循环里多大比例的窄决策可以从生成式 LLM 上卸下来"。
- 其价格/延迟量级可作预算分配与级联升级阈值的基线（以实测为准）。
- 与 CLM-8B 构成"托管 vs 自托管"同档对照：供应商锁定与私有化约束的权衡样本。
