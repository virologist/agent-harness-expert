> **列说明**：
> - Pattern-Key 格式：`PK-<域>-<序号>`，域如 `coder` / `tester` / `mode2` / `schema` 等
> - 首次见：YYYY-MM-DD（首次出现该模式的时间）
> - 复现数：在多少个独立任务/会话中复现过
> - 状态：`pending`（待晋升）/ `promoted`（已晋升为团队规则）/ `archived`（已废止）
> - 来源：哪个成员首次提出 / 哪个任务触发
> - 简述：≤30 字一句话总结

## 采集协议

1. **候选条目产生**：coder / tester 完成阶段产出后，在 SendMessage 回传的 `summary` 字段末尾附 `candidates: [PK-<域>-<序号>: <一句话描述>, ...]`（≤2 条；无候选则填 `candidates: []`）
2. **去重与合并**：主理人在阶段收尾时按 Pattern-Key 去重；新条目写入本表，状态 `pending`
3. **晋升规则**：复现数 ≥2 的 `pending` 条目自动晋升为 `promoted` 状态，列入下一版 P0/P1 优化候选
4. **废止规则**：与新规则冲突的旧条目可标 `archived`；废止须有理由说明
