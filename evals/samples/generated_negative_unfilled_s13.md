## 4. 六层设计（每层 = 决策 + 落地规格）

### 4.1 E 执行循环

#### E1 终止条件归属
终止条件归属 V 层验证接口，模型自评禁止。终止条件必须由独立上下文裁判判定。

#### E2 防跑飞三保险
防跑飞设三道保险：轮次上限 + token 预算 + 每节点超时，三者缺一不可。

#### E3 静态模式 vs 动态脚本
任务结构清晰时用静态模式（步骤可枚举），不清晰时用动态脚本（运行时编排）。

#### E4 失败回喂
错误必须作为观察结果回喂模型，按瞬时/模型/永久/资源四类分类恢复。

#### E5 打转检测
打转检测靠连续 N 次相同工具名 + 参数指纹识别，命中即打断。

#### E6 循环内分档
循环内异质步骤按四分类档位分派，避免同档模型大炮打蚊子。

#### E7 策略选择器
策略选择器由确定性代码 / 决策型模型实现，低置信度升级到主 LLM。

#### E8 墙钟预算与并行
墙钟预算与并行度上限由有界池管控，依赖未理清不得并行。

#### E9 流式与可中断
流式与可中断：是否流式输出 + 取消时已发生副作用清单可补偿/不可逆。

### 4.2 T 工具

#### T1 工具接入与接口标准化
工具接入与接口标准化：所有工具按统一 schema 注册，接口稳定。

#### T2 按需筛选子集
按需筛选子集：活跃工具过多时降级到当前任务相关的子集。

#### T3 工具执行位置
工具执行位置：本地进程 / 沙箱 / 远程，写操作影响半径划定。

#### T4 凭证不进执行环境
凭证不进执行环境，凭证走外部代理或受控入口注入。

#### T5 注册≠披露≠授权
注册披露授权分离：系统注册 ≠ 暴露给模型 ≠ 这次允许执行。

#### T6 模型组件接入形态
模型组件接入形态：工具 / 中间件 / 内联调用三种 + 降级链。

#### T7 披露序列稳定
披露序列稳定：按需筛选的子集顺序与 schema 序列化必须确定。

### 4.3 C 上下文

#### C1 窗口预算分配
窗口预算分配：系统指令 / 历史 / 工具结果 / 参考资料各占多少。

#### C2 压缩与摘要时机
压缩与摘要时机：用多少比例后质量开始下降即触发。

#### C3 噪音下沉
噪音下沉到子任务与文件，让 Agent 尽量留在干净上下文。

#### C4 每轮重新组装
每轮重新组装，不更新 = 用过时信息；工具调用与其结果成对保留。

#### C5 外部内容消毒
外部内容消毒：检索/网页/文件内容截断 + 标记为待分析数据。

#### C6 决策型模型 state 复用
决策型模型 state 复用上下文组装结果，避免重复花 token。

#### C7 前缀稳定
前缀稳定 ≠ 不更新：内容每轮重取但字节前缀不许变（缓存命中）。

#### C8 重写失效预算
重写失效预算：分段压缩保住头部，重写成本可预测。

### 4.4 S 状态

#### S1 存储结构与写入治理
存储结构与写入治理：JSON/KV/数据库 + Agent 不能直接篡改。

#### S2 失败后重新加载
失败后重新加载：可审计、可恢复的状态重建路径。

#### S3 并发写
并发写处理：WAL / 单写 / 连接池 三选一确定。

#### S4 外部副作用幂等
外部副作用幂等：外部写操作必须幂等键 + 状态查询 + 恢复策略。

#### S5 记忆治理
记忆治理：可信度标记 + 归属（用户/项目）+ 失效条件。

#### S6 证据版本绑定
证据版本绑定：验证结论只对被验证的版本有效，版本变旧结论失效。

### 4.5 L 生命周期

#### L1 拦截点
拦截点：鉴权、审计、策略执行、安全监控等动作的前置钩子。

#### L2 拦截不可绕过
拦截不可绕过：安检门不能被 Agent 自身修改。

#### L3 鉴权协议
鉴权协议：JWT / SSO / OIDC 协议级实现，不是「校验身份」一句空话。

#### L4 人在回路四档
人在回路四档：自动执行 / 执行后告知 / 执行前确认 / 直接阻断。

#### L5 高危纵深防御
高危纵深防御：前置 + 独立于分类器的二次校验。

#### L6 快筛阈值与放行率
快筛阈值与放行率：阈值与放行率定档，模型自身需抗注入。

### 4.6 V 评估

#### V1 独立验证
独立验证：Agent 说「成功」不算数，必须独立裁判。

#### V2 可量化可复现
可量化可复现：成功标准可量化、可复现，不是「看起来不错」。

#### V3 评估者分离
评估者分离：独立上下文 + 独立评分标准，不看执行者推理过程。

#### V4 显式标准与迭代预算
显式标准与迭代预算：评估标准显式 + 迭代预算防死循环。

#### V5 回执≠业务事实
回执≠业务事实：HTTP 200 / 退出码 0 不代表业务对象进入目标状态。

#### V6 评测环境可比
评测环境可比：同一基础设施/数据/预算 + 防绕过任务。

#### V7 验证强度阶梯
验证强度阶梯：确定性规则 > 独立模型裁判 > 模型自评（禁止）。
